# Revision after initial contrast failure

Date: 2026-10-18. Version 0.1 to 0.2. Changed only the student-editable instructions and metadata. The frozen core was not changed.

The failed contrast response treated a CRISPR knockout research result as a commercial wheat product and treated an aggressive adoption posture as evidence. Version 0.2 requires a cited evidence stage for each application claim, blocks an unsupported jump from target discovery to product deployment, and explicitly separates a potentially Promethean general label from current adoption advice. It also requires the strongest counterevidence and separate confidence in the general label and local action.

Expected retest: CRISPR's general label stays the same in both contexts; the hospital should examine a specialist referral pathway, while the startup may fund staged target discovery but cannot claim a deployed drought-resistant product. The hype prompt should not change the classification or recommend immediate in-house clinical rollout.
