# Promethean Technology Classification Agent

Assignment 4 specialist built from MASY1800_ET_Agent_Scaffold_v1_0. Use specialist_instructions.md with the unchanged core prompt and output schema. Version 0.3 uses controllably generated, distributed and verified quantum entanglement as its worked technology. The organization profiles are hypothetical test cases, not factual claims about named institutions. The earlier CRISPR tests in records/00–08 and responses/initial_contrast_1_response.json are retained as version 0.1–0.2 history; version 0.3 tests and raw independent ChatGPT replies are recorded separately.

Build a prompt with `python3 tools/build_prompt.py --agent agents/promethean_classification_agent --case agents/promethean_classification_agent/cases/primary.json`. The other case files use the same command. Save JSON responses under responses/ and run the unchanged response validator.

The agent offers a classification and bounded management implication, not a security certification or procurement decision. Evidence, test history, limitations and the independent judgment are in records/.
