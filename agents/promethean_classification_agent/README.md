# Promethean Technology Classification Agent

Assignment 4 specialist built from MASY1800_ET_Agent_Scaffold_v1_0. Use specialist_instructions.md with the unchanged core prompt and output schema. This package uses CRISPR genome editing as a worked example; the organization profiles are explicit hypothetical test cases, not factual claims about named institutions.

Build a prompt with `python3 tools/build_prompt.py --agent agents/promethean_classification_agent --case agents/promethean_classification_agent/cases/primary.json`. The other case files use the same command. Save JSON responses under responses/ and run the unchanged response validator.

The agent offers a classification and bounded management implication, not clinical, regulatory, or investment advice. Evidence, test history, limitations and the independent judgment are in records/.
